    Attiva l’accesso con un clic

    Una volta sola, e solo per te: chi scarica l’hub non farà mai questa procedura, trova l’accesso già pronto. GitHub non autentica applicazioni che non siano registrate, ma il passaggio finisce qui: niente file da aprire, niente da ricompilare.

    1. Registra l’applicazione. Il modulo si apre già compilato: premi solo Register application, in fondo alla pagina.
      Se i campi risultassero vuoti, copiali da qui
      Application name —
      Homepage URL —
      Callback URL —
    2. Incolla le due stringhe. Il Client ID è già lì; il secret compare premendo Generate a new client secret. Se li inverti, ci penso io.
    3. Salva e prova. Controllo il Client ID con GitHub, salvo cifrato sul tuo PC e provo subito l’accesso, così vedi se funziona davvero.

    Restano su questo PC, cifrate con DPAPI. Perché valgano anche per chi scarica l’hub devono finire in config.py prima di ricompilare.
